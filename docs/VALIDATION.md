# 实际验证记录

日期：2026-10-16。构建、主机实验与真实硬件测量分开记录。

## 目标编译与链接

Keil MDK-ARM Lite 5.43 / ARMCC 5.06 update7 build960，C99、MicroLIB、O2、M4F：

| 目标 | 错误/警告 | Code+RO+RW保守Flash | RW+ZI RAM | 距32KB余量 |
|---|---|---:|---:|---:|
| Full：频谱+BFSK+Modbus+导出 | 0/0 | 30980B | 56904B | 1788B |
| BFSK_Lite：无频谱 | 0/0 | 14844B | 36312B | 17924B |

RAM包含静态任务栈、工作区及MSP预留。只使用F407普通SRAM128KB，未把DMA放CCM。ARMCC的Flash为未假定初始化压缩收益的保守合计。余量小，后续代码增加可能越过评估限制。

Arm GNU 15.2.Rel1完整固件编译链接成功：FLASH区域35024B；RAM区域56968B，包含4096B MSP预留。GCC镜像大小不能拿来证明Keil是否受32KB限制。日志与结构化指标在validation/。

## 主机检查

- WSL GCC 13.3，C99；核心Wall/Wextra/Werror/Wpedantic。
- 三组CTest通过：核心数据/协议契约，BFSK完整帧接收，Modbus事务。
- ASan+UBSan构建下三组通过；CMSIS主机后端亦编译了检查插桩。
- BFSK覆盖0..79全部初始样点偏移、坏CRC、重新同步和采样断流。Modbus覆盖读、非法范围、广播、校验错误及写入原子拒绝。
- NumPy独立参考：自有主机FFT和实际CMSIS标量后端各10组/310窗口；CMSIS带检查插桩构建再次10组/310窗口通过。主机后端禁用ARM指令，不能代替M4时序验证。

已知625Hz、0.6V峰值合成量化码末窗：624.999939Hz、0.599942029V峰值、0.424223512V AC RMS。非整bin637.3Hz样例：估计637.222534Hz，但幅值0.533106148V仍有约11.15%栅栏误差，没有宣传高精度全频测量。

1kHz低通对2kHz单音稳态衰减约-15.437dB，符合软件理论频响；6500Hz按8kSa/s采样观测为1500Hz，展示无法事后挽回的混叠。

## BFSK实验

详见BFSK.md及validation/bfsk/report.json。已知符号边界的5档Eb/N0共10000bit，对照非相干正交BFSK理论趋势；完整接收机7组、每组6帧，包含量化/限幅、噪声与时钟偏差。

无噪声、0.05V/0.2V噪声、±200ppm和+1000ppm的本次短样例均6/6有效。2V强噪声样例0/6，PER=1，未组帧payload BER=null。有限样本0错不是零真实BER；没有持续定时PLL或通用时钟容限保证。
