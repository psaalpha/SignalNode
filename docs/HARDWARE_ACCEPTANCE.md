# 硬件验收：全部等待真实设备执行

已完成的是源码、Keil/GCC链接、主机数值与协议验证。尚未烧录，也未假定用户已有某一型号F407开发板；先核对原理图，默认8MHz HSE，接线见FIRMWARE_GUIDE。

- [ ] 核对芯片、HSE、VDDA、调理电路、逻辑电平和PA0/PA4/USART/PB1冲突。
- [ ] 实测8kSa/s和ADC数据连续性，保存原始数据与信号源设置。
- [ ] 受控100..1000Hz、整bin/非整bin单音扫频，对照原始与滤波RMS/频谱，记录校准前后误差。
- [ ] 模拟前端通带与抗混叠测试，识别近轨/削顶及信号源谐波。
- [ ] 测ADC ISR最大耗时、DSP每块最大耗时、队列余量和四个任务栈水位。
- [ ] 正常负载1小时连续运行，核对28,800,000个样本、56,250个块的开始/停止边界与丢块计数。
- [ ] 注入DSP延迟、导出拥塞、ADC/DMA错误，检查索引断裂、重同步、预热和看门狗。
- [ ] 核验19200 8E1、RTU边界等待、USART TC后释放DE、CRC/长度/地址/广播行为。
- [ ] 主机不接收原始导出时，确认采样仍进行，并区分采集/导出丢块。
- [ ] 单板DAC→ADC回环，记录BFSK同步/有效帧/错误计数和真实输出频率。
- [ ] 独立板卡或信号源发送，测试初始相位、幅度、频偏、噪声、时钟偏差和长时间PER/BER。

设计目标（非已达成）：DSP每块<10ms、ADC ISR固定复制<80us、正常负载1小时无采集丢块。单音频率和幅值精度需限定频带、输入幅度、参考源、前端及校准条件。仿真短帧全对不能推导真实链路零误码。

同板DAC与ADC共享时钟，只证明通路，不能代替独立时钟测试。项目不承载电机控制，不具备工业认证或精密仪器校准结论。
