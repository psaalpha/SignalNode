# BFSK链路与统计定义

正式功能：500Hz表示0，1500Hz表示1，100bit/s，8kSa/s，每符号80点。两个音在80点DFT上为5/15号bin，使用矩形符号区间的非相干双通道Goertzel能量判决。

发射器使用16点正弦LUT，分别每样点步进1/3，DAC码2048±1000。每个符号恰有5/15周期，符号边界保持相位连续。TIM6+DAC DMA以160点双半缓冲持续运行，空闲输出2048。默认每5秒准备16字节已知测试payload。

## 帧

`55`重复8字节 → 同步字`D3 91 A6 5C` → 序号2字节大端 → payload长度1字节 → 0..32字节payload → CRC16低字节/高字节。

每个字节MSB先发。CRC16多项式0xA001、初值0xFFFF，覆盖序号、长度、payload。16字节payload的完整帧264bit，即2.64秒；32字节payload为3.92秒。净载荷速率低于100bit/s，不能把调制比特率当应用吞吐率。

## 接收与恢复

搜索期每20点评估一次80点窗口，维护4路符号时相假设。先发现足够长的交替前导，再匹配32位同步字。锁定后仅按所选时相每80点判决，组装长度、payload和CRC。

低能量持续8个符号、非法长度、完成一帧或采样索引断裂均重新进入搜索。CRC失败的完整帧仍可交给诊断回调，应用必须检查crc_ok才接受业务数据。当前没有持续符号定时PLL，也没有纠错编码、重传或自动增益控制。

## 统计必须分开

1. `known_timing_ber`：已知符号边界、理想AWGN浮点模型，C Goertzel实际判决，与非相干正交BFSK理论趋势比较。它不含同步、ADC量化或限幅。
2. 完整接收机PER：独立NumPy发射波形经过时间轴重采样、噪声、12bit量化和0..3.3V限幅，再由C接收机从任意位置捕获。PER=(已发帧-有效帧)/已发帧。
3. `observed_payload_ber`：只对能完整组装、序号可匹配的帧比较payload，CRC失败的完整帧也包括在内。缺失帧仍计入PER；没有可比较payload时BER为null，不能报告“零误码”。
4. 板上36/38号寄存器是固定测试pattern比较的错误位数/已比较位数，仅在发送端使用项目已知pattern时有意义，不是任意业务数据的真实BER。48号是已准备发送的序号计数模65536，结合DAC错误和接收序号观察，不能等同物理交付证明。

## 本次仿真

固定随机种子20261016。已知边界测试每档2000bit：Eb/N0为-4、0、4、8、12dB时，错误数855、617、290、48、0；有限样本0错不表示真实BER=0。

完整接收机每种条件6帧：无噪声、0.05V/0.2V噪声标准差，以及±200ppm、+1000ppm样例均6/6有效；2V强噪声样例0/6，PER=1，payload BER=null。单组短仿真不能给出通用噪声/时钟容限。JSON报告在validation/bfsk/report.json。

无噪声C测试覆盖全部0..79初始样点偏移、CRC破坏、坏帧后重新捕获、采样断流。仍需真实独立时钟、模拟通道、幅度扫描、频偏和长时间误码统计。
