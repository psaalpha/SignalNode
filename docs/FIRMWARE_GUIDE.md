# F407 SPL固件联调指南

目标：STM32F407VGT6，8MHz HSE，168MHz系统时钟；C + SPL V1.8.0 + FreeRTOS 11.1.0。尚未烧录实测，以下接线必须先对照具体开发板原理图。

## 接口

| MCU引脚 | 功能 | 连接 |
|---|---|---|
| PA0 | ADC1_IN0 | 经调理的0..VDDA模拟输入 |
| PA4 | DAC1 BFSK输出 | 初次同板回环可经1kΩ串联到PA0 |
| PA9 | USART1_TX 921600 8N1 | 3.3V USB-UART RX，用于原始数据 |
| PA2 | USART2_TX 19200 8E1 | 3.3V RS485模块DI |
| PA3 | USART2_RX | RS485模块RO |
| PB1 | RS485 DE与/RE | 两者接PB1；高电平发送，低电平接收 |
| SWDIO/SWCLK/GND | 调试 | ST-Link |
| GND | 参考地 | 低压实验设备共地；独立设备需核对接口电气条件 |

只有低压受控实验输入。3.3V是标称参考，ADC输入范围取决于真实VDDA；不能直接接±电压、24V或电机线。初次接通前测输入电压。板内DAC与ADC共时钟，同板回环不能证明独立时钟容限。

上电后静态创建4个任务/队列，DSP任务开放ADC/DAC/串口，监测任务启动看门狗。`SN_AUTO_BFSK_TX=1`默认每5秒自动准备测试帧，可设0改为仅Modbus触发。程序无控制电机功能。

## 构建

Keil打开`keil/SignalNode.uvprojx`，选择Full或BFSK_Lite，ARMCC5.06、C99、MicroLIB、M4F浮点。完整版本的32KB余量较小，不宜在控制路径直接加入printf浮点输出。GCC方式见README；两种map不能混用。

CPU普通SRAM上限128KB，CCM不用于DMA。Keil启动MSP预留4096字节；RTOS任务栈在静态数组中另计。

## Modbus寄存器

设备地址17、19200、8E1。功能04读输入寄存器；06/16写保持寄存器。PDU偏移从0起，寄存器内大端，多寄存器高字在前。不要把30001/40001显示编号直接当PDU偏移。

| 输入寄存器偏移 | 长度 | 内容 |
|---:|---:|---|
| 0..3 | 各1 | 版本、Fs、FFT点数、步长 |
| 4 | 1 | bit0=频谱有效；bit8=包含频谱功能 |
| 5 | 1 | 已应用配置代号 |
| 6 | 2 | 已处理采样块数 |
| 8 | 4 | 分析窗首采样索引 |
| 12/14/16 | 各2 | 均值/原始AC RMS/滤波AC RMS，mV |
| 18 | 2 | 插值主频，mHz；单位细不等于精度高 |
| 20/22/24 | 各2 | 近轨样本/采集丢块/导出丢块 |
| 26 | 2 | 最大DSP耗时us |
| 28/30/32/34 | 各2 | BFSK同步/CRC有效帧/CRC错误/非法长度 |
| 36/38 | 各2 | 固定pattern错误位数/已比较位数 |
| 40 | 2 | 最后组帧序号，可能来自CRC失败的诊断帧 |
| 42/44/46 | 各2 | ADC错误/最大ADC ISR耗时us/RTU队列丢帧 |
| 48/50 | 各2 | 已准备TX序号模65536/DAC错误 |

保持寄存器0：低通截止0=旁路，否则100..2000Hz；1：0矩形窗/1 Hann；2：写1请求发送测试帧。发送器忙返回异常6。Full模式的配置在块边界生效，滤波首窗预热无效。Lite模式不产生频谱结果，滤波配置不产生处理效果，应查看输入寄存器4能力位。

## 电脑工具

`pip install -r requirements.txt`后，运行`tools/sn_client.py --help`。read/send-bfsk使用USB-RS485端口，capture使用独立USB-UART端口，不能互换。

原始帧头20字节：`SN`、version:uint8、type:uint8、payload_length:uint16、seq:uint32、first_sample:uint64、Fs:uint16，整数小端；随后1024字节ADC码和2字节CRC。类型1含512个小端uint16采样值。ADC文件保存采样索引，缺口需结合设备两类丢块计数解释。

## 首次上板顺序

1. 核对HSE=8MHz、芯片/供电与引脚冲突，先检查空闲DAC电压和VDDA。
2. 观察TIM/ADC采样节拍及原始数据连续性；不接信号时仅记录噪声。
3. 用625Hz受控信号检查ADC码、RMS和频谱，记录真实幅值/参考电压。
4. PA4经电阻回环到PA0，检查BFSK同步/有效帧计数；再用独立板卡/信号源验证时钟与通道。
5. 对照逻辑分析仪核验RS485字符格式、DE释放、帧间隔和异常恢复。
6. 测DWT最大耗时、任务栈水位、1小时丢块和看门狗故障行为。验收表未完成前不宣称硬件稳定。
